# Папка моделей

Ваги Robinhad/RVC **не** в Git (великі / особисті). Після clone запустіть
`tools\setup_*.ps1`. Файли стилів StyleTTS2 (`voices/*.pt`) можуть бути в репо.

## Структура

```
models/
  robinhad/          ← модель Robinhad (завантажується tools\setup_robinhad.ps1)
  styletts2/
    voices/          ← 30 файлів стилів голосу (tools\setup_styletts2.ps1)
  uploads/
    rvc/             ← ваші .pth + .index, завантажені через інтерфейс
```

## Як додати власну RVC-модель

1. Покладіть `.pth` та (опційно) `.index` у `models/uploads/rvc/`, або
2. Увімкніть прапорець у розділі **"🎙️ Гібрид"** (пункт 4) у головному
   інтерфейсі (`http://127.0.0.1:7900` після запуску `start_voice_studio.bat`)
   і завантажте файли там.

Де знайти українські RVC-голоси — див. `docs\UKRAINIAN_MODELS.md`.

## Формат файлів

| Файл | Опис |
|------|------|
| `*.pth` | Модель RVC (обовʼязково) |
| `*.index` | FAISS-індекс для кращої схожості (рекомендовано) |
